# Tienda en Línea de Productos — TechStore

Tienda en línea de productos de **tecnología y electrónica** (celulares, laptops, audífonos, tablets, smartwatches y accesorios).

## Product Backlog e Historias de Usuario

### Funcionales — Prioridad Alta

| ID | Historia de usuario |
|----|----------------------|
| RF01 | Como cliente nuevo, quiero crear una cuenta con mi nombre, correo, contraseña, teléfono y dirección, para poder comprar productos e iniciar sesión en el futuro. |
| RF02 | Como cliente registrado, quiero iniciar sesión con mi correo y contraseña, y poder cerrar sesión, para acceder a mi cuenta de forma segura. |
| RF04 | Como cliente, quiero ver un catálogo de productos con imagen, nombre, categoría, precio y disponibilidad, para explorar lo que puedo comprar. |
| RF05 | Como cliente, quiero buscar productos por nombre, para encontrar rápido lo que necesito. |
| RF06 | Como cliente, quiero filtrar productos por categoría, rango de precio, popularidad y disponibilidad, para reducir las opciones a lo que me interesa. |
| RF07 | Como cliente, quiero ver el detalle completo de un producto, para decidir si lo compro. |
| RF08 | Como cliente, quiero agregar productos al carrito, para juntar lo que quiero comprar. |
| RF09 | Como cliente, quiero modificar la cantidad de un producto en mi carrito, para ajustar mi compra. |
| RF10 | Como cliente, quiero eliminar productos del carrito, para corregir mi selección antes de pagar. |
| RF11 | Como cliente, quiero registrar mi pedido al finalizar la compra, para que la tienda procese mi orden. |
| RF12 | Como cliente, quiero consultar mi historial de pedidos, para revisar qué he comprado y en qué estado está. |
| RF13 | Como cliente, quiero completar el proceso de pago de mi pedido, para concretar la compra. |
| RF16 | Como administrador, quiero crear, consultar, actualizar y eliminar productos (CRUD), para mantener el catálogo actualizado. |
| RF17 | Como administrador, quiero administrar las categorías de productos, para mantener organizado el catálogo. |
| RF18 | Como administrador, quiero administrar los usuarios registrados, para gestionar cuentas y permisos. |
| RF19 | Como sistema, quiero exponer los datos de productos, categorías y pedidos mediante una API en formato JSON, para que el frontend consuma la información. |

### Funcionales — Prioridad Media

| ID | Historia de usuario |
|----|----------------------|
| RF03 | Como cliente que olvidó su contraseña, quiero poder recuperarla mediante mi correo, para no perder el acceso a mi cuenta. |
| RF14 | Como cliente que ya compró un producto, quiero dejar una reseña y calificación, para compartir mi experiencia. |
| RF15 | Como cliente, quiero guardar productos en una lista de deseos, para consultarlos o comprarlos después. |
| RF20 | Como cliente, quiero recibir una confirmación de mi pedido, para tener constancia de que se registró correctamente. |

### No funcionales

| Categoría | Requerimiento |
|-----------|---------------|
| Seguridad | Contraseñas con hash, consultas preparadas (PDO), control de sesión y permisos por tipo de usuario, HTTPS en producción. |
| Usabilidad | Interfaz intuitiva, organizada, compatible con dispositivos móviles, mensajes de error claros. |
| Rendimiento | Consultas eficientes, imágenes optimizadas, uso apropiado de JavaScript. |
| Diseño | Diseño responsivo, tarjetas para productos, formularios organizados, navegación consistente. |

## Categorías propuestas

Celulares · Laptops · Audífonos · Tablets · Smartwatches · Accesorios
